# Stage A baseline (1 second silence timer)

Clean 12-turn session, Chrome, browser speech recognition, Gemini free tier, browser speech synthesis.

| Measure | Result |
|---|---|
| Turns | 12 |
| Cut-offs (self-reported) | 2 (about 17%) |
| Long gaps (self-reported) | 0 |
| Mean total delay | about 2.04 s (median 1.97 s) |
| Silence wait | about 1.05 s |
| Model reply | about 0.88 s |
| Speech start | about 0.10 s |

Delay is measured from the last recognised word, so the true delay is slightly longer.
